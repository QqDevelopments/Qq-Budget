# Qq Budget Privacy Policy

This repository contains the English and Turkish privacy policy for Qq Budget's Android app. `index.md` is the source of the GitHub Pages website; `_config.yml` selects the supported Minima theme.

## Publish with GitHub Pages

1. Review `index.md` against the actual Android release, AdMob privacy messages, configured ad partners, and Google Play Data safety answers before publishing. Complete the outstanding consent and release checks in the Android project.
2. Commit and push these files to the repository's default branch.
3. In GitHub repository settings, open **Pages**, select **Deploy from a branch**, and choose the default branch and `/ (root)`. Save the setting.
4. Wait for the Pages deployment, then open `https://qqdevelopments.github.io/Qq-Budget/` in a private browser session. Confirm both languages, links, HTTPS and access without sign-in. The address is expected from the current GitHub repository identity and must be verified after deployment.
5. Add the verified policy URL in Play Console and make it accessible from within the Android app. Review the policy and Data safety form whenever data practices, SDKs or advertising settings change.

The current policy describes the ad-enabled Android implementation; the previously signed Android 1.0.1 bundle predates it. Publishing this repository does not release the app, configure AdMob messages, or establish policy compliance. The AdMob `app-ads.txt` file is a separate requirement associated with the developer website listed in the store; it is not created here.
